# 컷별 표 스키마 (cut-table)

보고서의 핵심 산출물. 프레임(비전 판독)과 자막(전사)을 시간축으로 조인한 결과물.

## 마크다운 형식

```markdown
## 컷별 분석

| # | 타임스탬프 | 화면에 보이는 것 | 화면 텍스트 | 실제 대사 |
|---|---|---|---|---|
| 1 | 00:00-00:03 | (비전: 프레임 묘사 — 인물/사물/장면 구성) | (화면에 쓰인 글자, 없으면 —) | [0000.0s] 자막 문장 |
| 2 | 00:03-00:07 | ... | ... | [0003.7s] ... |
```

## 규칙

1. **컷 구분 기준**: frames/의 프레임 경계 = 컷 경계. 프레임 N장이면 컷 N개.
   transcript의 타임스탬프 `[0000.0s]`를 컷 구간에 배정한다 (프레임 사이 시작분).
2. **화면 텍스트가 없으면** `—` (빈 칸 금지 — "없음"과 "누락"의 구별).
3. **대사가 없는 컷** (B롤, 무음): `—` 처리.
4. **타임스탬프 형식**: `MM:SS-MM:SS` (컷 구간). 자막 인용은 원본 `[SS.Ss]` 유지.
5. **프레임 파일 대응**: 각 행이 frames/의 어느 파일에서 왔는지 필요 시 각주로
   기록 (scene_01.jpg 등) — 검증 가능성 확보.

## 보고서 전체 구조 (페르소나 계약 §3)

```
1. 후킹 멘트 (최상단, 별도 강조 — 영상 도입부의 훅 인용)
2. 컷별 분석 (위 표)
3. "왜 이 구조가 먹히는지" 분석
4. "내 콘텐츠에 적용할 점" 제안
```

언어: 항상 한국어.
