# 컷별 표 스키마 (cut-table)

보고서의 핵심 산출물. 프레임(비전 판독)과 자막(전사)을 시간축으로 조인한 결과물.

## 조인 기준축 (§6.1 — 반드시 지킨다)

- 조인 기준은 **영상 시작점 기준 경과 초**다. 파일명 순서가 아니다.
- 프레임의 시간 값: index.json의 `frames[].t` (파일명 `cut_NN_tSS.SSs.jpg`와 동일 값)
- 자막의 시간 값: transcript.txt의 `[SS.Ss]` 타임스탬프
- index.json의 frames는 이미 시간 정렬·중복 제거(0.4초 병합)가 끝난 상태로 기록된다.

## 마크다운 형식

```markdown
## 컷별 분석

| # | 타임스탬프 | 화면에 보이는 것 | 화면 텍스트 | 실제 대사 |
|---|---|---|---|---|
| 1 | 00:00-00:03 | (비전: 프레임 묘사) | (화면 글자, 없으면 —) | [0000.0s] 자막 |
| 2 | 00:03-00:07 | ... | ... | [0003.7s] ... |
```

## 규칙

1. **컷 구분**: frames/의 프레임 경계 = 컷 경계. 프레임 N장 = 컷 N개.
   transcript 문장은 `t` 값이 속한 컷 구간에 배정한다.
2. **화면 텍스트가 없으면** `—` (빈 칸 금지 — "없음"과 "누락"의 구별).
3. **대사가 없는 컷** (B롤, 무음): `—`.
4. **타임스탬프 형식**: `MM:SS-MM:SS`. 각 컷의 시작은 해당 프레임의 `t` 값,
   끝은 다음 컷의 `t` 값 (마지막 컷은 영상 길이까지). 자막 인용은 `[SS.Ss]` 유지.
5. **프레임 파일 대응**: 필요 시 각주에 원본 파일명(cut_01_t000.00s.jpg) 기록 —
   검증 가능성 확보.

## 보고서 전체 구조 (페르소나 계약)

```
1. 후킹 멘트 (최상단, 별도 강조 — 영상 도입부의 훅 인용)
2. 컷별 분석 (위 표)
3. "왜 이 구조가 먹히는지" 분석
4. "내 콘텐츠에 적용할 점" 제안
```

언어: 항상 한국어.
