mailto 동작 점검

기기·브라우저별 mailto 링크 실동작 확인용 — 각 테스트 실행 후 메일앱이 열리는지, 본문이 온전한지 확인하고 결과를 기록하세요.

현재 환경

받는 주소

아래 모든 테스트에 이 주소가 사용됩니다.

기본 동작

mailto:주소 만 호출 — 메일 작성창이 열리는가, 어떤 앱이 뜨는가(메일앱/웹메일/아무반응없음)
주소+제목+본문(여러 줄, 본문에 URL 포함). 줄바꿈은 %0D%0A. 제목·본문이 제대로 채워지는지 확인
T2와 동일하나 줄바꿈을 %0A만 사용 — 줄이 한 줄로 뭉치는지 T2와 비교
bcc 파라미터 포함 — bcc 주소가 무시되는 클라이언트인지 확인(전송 전 bcc 필드 확인)

본문 길이 한계

각 길이의 본문을 넣어 열어봅니다. 본문 맨 끝에 [END] 표시 — 메일앱에서 [END]가 보이면 잘리지 않은 것.

웹메일 대체 경로

mail.google.com 컴포즈 딥링크 — 받는주소·제목·본문이 채워진 작성창이 열리는지
outlook.office.com/mail/deeplink/compose — 로그인 상태여야 작성창 확인 가능
네이버 메일 작성 화면 — 앱 설치 시 앱 연결, 미설치 시 웹 메일로 열림

클립보드 방식

navigator.clipboard.writeText — 붙여넣어 확인: "클립보드 텍스트 복사 성공" 이어야 함
ClipboardItem에 text/html + text/plain 동시 투입 (img는 공개 https URL) — 메일 앱·문서에 붙여넣어 이미지가 보이는지 확인. 미지원 브라우저는 아래에 에러가 표시됨.
